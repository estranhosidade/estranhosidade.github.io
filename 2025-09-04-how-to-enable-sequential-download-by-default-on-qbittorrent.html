How to enable sequential download by default on qBittorrent

04/09/2025 estranhosidade Deixe um comentário

“I really don’t like when someone tries to tell me how I should use a piece of software.”

If you don’t have the patience for my rambling and just want to learn how it’s done, skip to the word “TUTORIAL”.

There are some projects where the developer suffers from a kind of “small power syndrome” and refuses to implement features the community desperately wants. One example that comes to mind is NewPipe refusing to add SponsorBlock support on their third-party YouTube player, which led to the creation of New NewPipe, and a fallout over project guidelines.

Another example is the qBittorrent developer refusing – for up to 10+ years – to add the option allowing users to set sequential download to be default [¹] [²] [³] [⁴] [⁵]. The option exists, but it requires the user to manually enable it for each download. He has his reasons and the usual sermon of “Oh, it would be harmful if this was extensively used…” — honestly, you’re pirating movies, man. Cut the BS virtue signaling, you are a pirate, not Martin Luther King or something.

“There is a strong and growing power trip mentality (in the open source community)”

Anyway, it’s pretty annoying, because you usually end up facing the following scenario: you want to watch a movie, you click to download torrent, it goes to qBittorrent, but forget to tick that option. You wait five minutes, go to hit play, and only then remember you forgot to enable it! Then you have to wait another 3 or 4 minutes to download the beginning, and only then are you able to watch your movie or TV show.

At first, I tried recompiling qBittorrent from source code until I realized I wasn’t smart enough to figure that out and we’re still at least 6 or 7 ChatGPTs away from being able to just say, “Hey, ChatGPT, modify this code and compile it,” and get a neat little .exe. But then I remembered that qBittorrent has a web interface — since many people use seedboxes — and you can access program data in your browser, both inside and outside your local network. And that made me think: “Well, if there’s a web interface, maybe there’s also an API I can use to talk to qBittorrent installed on my computer”, and indeed, there is! From there, the process becomes much simpler — so simple that even an idiot like me could do it. I have been trying to find a solution to this issue for years and years. I finally found one.

TUTORIAL:

What programs will we need?
Besides qBittorrent itself, we’ll need:

• Python, which will be required to run our Python script:
https://www.python.org/downloads/

• AutoHotkey, simply to hide the Python window our script will create. Technically this step is optional, but I’d recommend doing it, because otherwise you might accidentally close the window:
https://www.autohotkey.com/download/

• This Python script I̶ ̶w̶r̶o̶t̶e̶ ChatGPT made it for me. The code will constantly — every 10 seconds — send requests essentially saying: “Check all existing torrents, enable ‘Download in sequential order’ (toggleSequentialDownload) and ‘Download first and last pieces first’ (toggleFirstLastPiecePrio) for all of them.” The script will run in a loop that keeps sending this request:
https://archive.org/download/blogfilesx/qBittorrentsequentialbydefault.py

What to do?

1) Open qBittorrent, go to the Web UI option, and configure it as shown in the image below (be sure all checkboxes are identical), then click OK. After that, download our Python script and run it. Assuming both the IP and port are the same, it should work. Both the Python script and our new qBittorrent setting will point to the same local IP/port, 127.0.0.1:8085. This will allow our code to control the torrent client. If the qBittorrent asks for a password, just set it as 123456 – don’t worry, this won’t be a problem because we are using a localhost IP, so it is not accessible outside your local network.

2) Download our Python script and choose a folder to put it in. Let’s suppose:
“C:\Code\qBittorrentsequentialbydefault.py”

3) Make an AutoHotkey script that will run this Python script with Windows hidden (because Microsoft is stupid and never implemented an easy option to initiate folders without a GUI on Windows). You can simply create a text file and put the single following line there:
Run, “C:\Code\qBittorrentsequentialbydefault.py”,, Hide

Then change its extension from .txt to .ahk, so AutoHotkey runs it. To keep consistency let’s name our file “qBittorrentsequentialbydefault.ahk”.

4) Almost there. Now we already have:

  • The qBittorrent settings configured correctly
  • The Python script that will constantly tell qBittorrent to enable sequential mode for all downloads
  • The AutoHotkey script that executes the Python script communicating with qBittorrent and hides its window.

5) The only thing left is to adjust so that our AutoHotkey code starts alongside Windows. For that it’s quite simple. Type shell:startup in Windows Explorer or using the Windows+R command. This will take us to the Windows startup folder; any shortcut or file placed there will automatically start up alongside Windows. Then paste our qBittorrentsequentialbydefault.ahk file (don’t create a shortcut; put the .ahk file there directly, to make it simpler).

6) And that’s it. Now every time you run Windows, the code will start automatically. The script is pretty lightweight, so it won’t be a problem to keep in the background since it just sends a few requests on the local network. To finish it off, since the code is still not running (because we didn’t restart Windows yet), just click on the AutoHotkey code we just created and it will run our script in the background. Now, every time you add a torrent, it will automatically be set to sequential mode, as well as prioritizing the first and last pieces of a file first.

Here is an example of our code working (if you click the python script directly to see the window): at first, the code gives us an error, because it couldn’t find qBittorrent, since the software wasn’t open. When we run qBittorrent it shows us a series of message “All torrents already configured.”, signaling it is looping. When we add a new torrent, it automatically sets sequential download to default “Updated 1 torrent: sequential + first/last piece enabled.”

The tutorial assumes you are using Windows, but if you are on Linux or any other OS, the process is usually the same on the Python side — the only difference is that you will have to use another tool if you want to hide that python window.

I didn’t pay any attention to code itself, just asked the computer to create it, feel free to improve it
