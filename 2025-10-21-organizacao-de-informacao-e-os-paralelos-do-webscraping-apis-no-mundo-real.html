Organização de Informação e os Paralelos do Web Scraping/APIs no Mundo Real…

Se você quer dados de algum site, existem duas formas de consegui-los: você pode usar uma API (application programming interface), que é essencialmente uma interface de envio de informações que o site controla e lhe oferece (cobra) para compartilhar tais dados. Essa API tem contato direto com o banco de dados da plataforma.

E tem o web scraping, que é conseguir esses dados de forma “raiz”. Então, por exemplo, suponhamos que você queira extrair o texto de um fórum: você simula uma requisição de um navegador e, se tudo correr bem, tem acesso a esses dados. Já no uso de APIs, o acesso é fornecido àquele determinado arquivo diretamente no banco de dados do site. Estou simplificando.

O web scraping é mais complexo (geralmente as plataformas impõem dificuldades, como captchas, limites por IP, exigência de cadastro, fingerprinting para banir usuários tentando fazer web scraping, processos na justiça, etc.), porém, com ele, você tem acesso a uma quantidade de dados que talvez não seja coberta pelas APIs. O simples fato de um site oferecer uma API não significa que ele forneçam acesso a todos os seus dados por meio dela e, pior ainda, alguns sites nem sequer oferecem APIs, ou seja, não existe nenhuma forma de conseguir aquela informação além do web scraping.

Com o web scraping, teoricamente você tem acesso a qualquer parte disponível publicamente no site, porém existe o desafio de evadir os mecanismos que a plataforma eventualmente implemente para impedir o scraping.

“Na era das redes sociais, muito do conteúdo (Big Data), quando criado, já é automaticamente organizado dentro de um determinado banco de dados. Por exemplo, as pessoas fazendo uma live no Instagram. Elas estão criando aquele conteúdo, e o registro já é automaticamente organizado dentro do banco de dados da Meta. Porém, esses dados, embora organizados na origem, não estão disponíveis para nós em tal formato.”

Logo, evidentemente, após baixar o conteúdo bruto e desorganizado via web scraping, existe o trabalho de converter esse material para um JSON ou outro formato estruturado. É, essencialmente, fazer uma espécie de engenharia reversa no banco de dados daquele site. Ou seja, você categoriza informações desorganizadas, enquanto no uso da API, essas informações já lhe são entregues de modo estruturado.

Enfim, penso que observamos esse paradigma de “web scraping” (coletar e organizar informação não organizada) e “API” (coletar dados já previamente organizados por algo ou alguém) em uma série de coisas, e dá para aplicar essa perspectiva a muitos outros temas. Muitos deles já abordados aqui no blog:

A) Dispositivos inteligentes VS robôs humanoides para propósitos gerais:

Há alguns anos, escrevi um texto chamado “A Internet das Coisas Analógicas”, no qual argumento que a melhor “geladeira inteligente” do mundo seria simplesmente um robô humanoide que abrisse a porta do eletrodoméstico, olhasse lá dentro e dissesse para você o que tem ali. Ou seja, um robô capaz de interagir com objetos, com o mundo real nos termos humanos, e coletar informações desestruturadas (esse é o futuro da automação e de robôs para propósitos gerais). Fazendo um paralelo, seria mais ou menos como se uma geladeira inteligente com sensores fosse um site que oferece uma API, e um androide capaz de categorizar o que você tem na sua geladeira fosse um web scraper.

B) Sites que (não) permitem pesquisar por todos seus dados na plataforma/exportá-los VS uma IA que grava tela constantemente e categoriza esses dados, tornando-os pesquisáveis, organizados, construindo um banco de dados de forma descentralizada:

Como mencionei em meu texto “Por que você não consegue achar aquele vídeo que assistiu há alguns dias?”, muitas plataformas online simplesmente não oferecem ao usuário acesso ao seu histórico de conteúdo acessado dentro do site (as fotos que você visualizou no aplicativo do Instagram, por exemplo). Uma solução seria uma IA que registrasse as informações que você vê e conseguisse categorizar esses dados a partir de imagens e vídeos. Essa é a proposta de projetos como o Windows Recall, por exemplo, algo a ser implementado na camada do sistema operacional. Imagino esse conceito evoluindo para sistemas agênticos (Agentic OSs), que, além de gravar o que você acessa, também conseguirão, eles próprios, acessar e categorizar informações (sua caixa de e-mail, mensagens no WhatsApp e afins).

E, mais futuramente, isso provavelmente será implementado também, e principalmente, no nível de uma lente de contato que registra toda a informação que você vê, categorizando-a instantaneamente – ou seja, o mundo analógico passando a ser categorizado digitalmente automaticamente.

Em última instância, acho que esse é um texto refletindo sobre organização de informação.
