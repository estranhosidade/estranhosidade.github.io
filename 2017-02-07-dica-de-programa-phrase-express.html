Dica de Programa: Phrase Express

Link 07/02/2017 estranhosidade Deixe um comentário

Faz tempo que não posto muitas dicas de sites e programas (aliás, acho que nunca dei nenhuma dica de programa aqui), enfim, estou há séculos para escrever um artigo sobre RSS e sobre o Feedly, mas enquanto não arranjo tempo para isso, gostaria de recomendar esse ótimo programa chamado “Phrase Express”.

Eu acabei descobrindo ele ao tentar achar algum plugin para o navegador que desempenhasse o papel dele. É basicamente um programa no qual você pode ajustar para que toda vez que você digitar uma palavra ele a ajuste para outra.

Então, por exemplo, você pode configurar para que toda vez que você digitar a palavra “vc” ele ajuste automaticamente para “você“. Um dos maiores usos dele, para mim, é utilizá-lo como uma espécie de corretor automático, principalmente porque eu digito muito rápido e sempre acabo escrevendo algumas palavras erradas. Então, se eu digito “sera” ele já muda automaticamente para “será”, por exemplo.

Embora, haja várias outras utilidades para ele, por exemplo: você pode utilizá-lo como um tradutor de palavras. Pode configurar para que toda vez que você digitar “\” depois de uma palavra, como “casa\” ele automaticamente traduz a palavra para um determinado idioma, o utilizando como um acesso rápido ao dicionário.

Isso é uma função muito útil se você já sabe um idioma o suficiente para conseguir se expressar, mas ainda possui um vocabulário de palavras limitado. Então, por exemplo, você está digitando uma frase em inglês “Oh, I like very much of…”, e você quer dizer “abacaxi”, mas esqueceu como se diz isso em inglês, então você simplesmente digita “abacaxi\” e o programa busca no banco de dados e traduz para “pineapple”.

Outra coisa interessante é que se houver duas ou mais palavras diferentes num idioma para expressar uma palavra em português, e houver um conflito, o programa pede para você dizer a qual palavra você está se referindo. Então, suponhamos que você digitou “falta\“, e você configurou que a tradução pode ser “lack” ou “shortage”, o programa pede para você escolher qual das duas palavras você quer que ele ponha.

Muito resumidamente, é isso. Entretanto, ele não é especificamente focado nisso (então você talvez encontre alguma estranheza no começo, caso você já vá mexer nele achando que ele serve para isso). Ele fornece a opção de substituir palavras, e você usa a criatividade para usar ele de N formas interessantes, entre tais, as que mencionei aqui.

Ainda há uma série de outras opções mais avançadas, tais como, por exemplo, desativar ou ativar comandos em sites e programas específicos.

Para quem se interessar, segue o link do programa, e o link do “banco de dados” criado por mim, onde há configurações de tradução de palavras do português para o inglês, e de correção automática das palavras em português e em inglês.
